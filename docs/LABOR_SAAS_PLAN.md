# 알바 근무·급여·신고 웹앱 — 새 프로젝트 계획서

작성 2026-11-03 · 초안. 출발점은 Hiyorisando POS·ERP(이 저장소)의 인사 → 급여정산 → 신고 서류 흐름이다.
법·요율 숫자는 작성 시점에 아는 값이고 **출시 전 전부 공단·국세청·노무사 확인이 필요하다** (표시: ⚠️확인).

---

## 1. 한 줄 정의

> 알바·단기 근로자를 쓰는 소규모 사장님이 **출퇴근 기록부터 급여, 근로계약서, 매달 신고 서류까지** 한 곳에서 끝내는 웹앱.

### 누가 쓰나

| 사용자 | 하는 일 |
|---|---|
| 사장님(owner) | 매장·알바생 등록, 근무 확인, 급여 확정·지급 기록, 계약서 작성, 신고 서류 내려받기 |
| 매니저(manager) | 근무 현황 확인, 출퇴근 정정 요청 처리 |
| 알바생(staff) | 출퇴근 찍기, 내 근무·급여 명세서 보기, 계약서 서명 |
| 출근 기기(kiosk) | 매장 태블릿에 상시 로그인 — 출퇴근 버튼만 |
| 세무사(viewer, 선택) | 사장님이 초대하면 신고 자료만 열람·다운로드 |

### 어떤 문제를 푸나

- 출퇴근을 카톡·종이로 받아 **월말에 시간을 다시 맞춘다.** 분쟁이 나면 근거가 없다.
- 급여를 엑셀로 계산하고 3.3%·4대보험을 손으로 뺀다. 주휴수당·가산수당을 빠뜨린다.
- **매달 15일** 근로내용 확인신고서(고용·산재)를 한글 양식에 손으로 채우거나 세무사에게 정리해 보낸다.
- 근로계약서를 안 쓰거나 종이로 쓰고 잃어버린다(미작성·미교부 과태료 대상 ⚠️확인).

### 차별점

일반 근태·급여 앱은 **"급여 계산"에서 끝난다.** 이 앱은 그 데이터로 **신고 서류와 세무사 전달 자료까지** 만든다.
이미 운영 중인 Hiyorisando에서 실제로 쓰며 검증한 흐름이다(2026-10월분 신고 자료를 이 방식으로 만들었다).

## 2. 기능 범위

요청한 5개 기능 + 이미 만든 3개 자산.

| # | 기능 | MVP | 출처 |
|---|---|---|---|
| 1 | 출퇴근 관리 | ✅ | 이 저장소 출근부(키오스크) 확장 |
| 2 | 근무 현황 조회 | ✅ | 출근부 보드 + 근무표 |
| 3 | 알바생 등록·관리 | ✅ | 인사탭 근무자 관리 |
| 4 | 급여 명세서 | ✅ | 급여정산 + 근무자 예상 급여 |
| 5 | 근로계약서 관리 | ✅ | 전자 근로계약서(이미 있음) |
| A | 전자 근로계약서 | ✅ | `components/ContractDocument.tsx`, `SignaturePad`, `WorkerSignModal` |
| B | 인건비 신고 엑셀(세무사 전달용) | ✅ | `insuranceExcel.ts` |
| C | 고용·산재 근로내용 확인신고서(일용) PDF | ✅ | `LaborReportDocument.tsx`, `InsuranceExportModal.tsx` |

### 2.1 출퇴근 관리

**하는 것**
- 알바생이 출근·퇴근을 찍는다. 방법은 셋 중 매장이 고른다.
  1. 매장 태블릿(키오스크) — 이름을 누르고 전화번호 뒷자리 확인 (지금 출근부 방식)
  2. 알바생 본인 휴대폰 — 로그인 후 버튼 (선택: 매장 근처 위치 확인 ⚠️개인정보 동의 필요)
  3. 사장님이 직접 입력·정정 (기록 남김)
- 퇴근을 찍으면 그날 근무가 **실측 시간으로 확정**된다. 계획 시간은 따로 보관한다(지금 구조 그대로).
- 휴게시간: 퇴근 시 선택(0·30·60분) 또는 근무 길이로 법정 최소 자동 적용(4시간당 30분 ⚠️확인).
- 일별·월별·기간별 근무 내역 자동 정리.

**분쟁 예방 장치**
- 모든 출퇴근 기록은 **수정 이력**을 남긴다(누가·언제·무엇을·왜). 지운 기록도 사라지지 않고 '취소'로 남는다.
- 알바생은 자기 기록을 항상 볼 수 있다. 정정은 '요청'으로만 하고 사장님이 승인한다.
- 근무표에 있는데 출근을 안 찍은 날 → 사장님에게 알림(지금 '출근 기록 없음'과 매일 아침 알림).

### 2.2 근무 현황 조회

- **오늘 보드:** 매장별로 지금 근무 중 / 퇴근 / 출근 전 / 지각(예정 시각 지남)을 한눈에.
- 날짜별 근무 인원, 매장별 · 기간별 근무 시간 합계.
- 근무표(선택 기능): 파트·시간대 배정, 지난주 복사, 휴무일. MVP에서는 "예정 근무" 입력만 단순하게.

### 2.3 알바생 등록·관리

- 기본 정보: 이름, 전화, 계좌, 주민등록번호(암호화 저장, 사장님만 열람), 입사일.
- 근로 조건: **시급**, 근무 형태(일용 / 단시간 / 상용 ⚠️유형별 규칙이 다르다 — 4장), 소속 매장(여러 매장 가능), 기본 공제(3.3% / 4대보험).
- 초대 링크로 알바생이 직접 가입·정보 입력 → 사장님은 확인만.
- 상태: 근무 중 / 퇴사. 퇴사해도 기록·서류는 보관 기간 동안 남긴다.

### 2.4 급여 명세서

- 근무 시간 × 시급 = 기본급, 여기에 **주휴수당·가산수당**(4장)과 수당/공제 조정 항목.
- 공제: 3.3%(사업소득), 4대보험(국민연금·건강보험·장기요양·고용보험), 일용근로소득세(일용직).
- 월별 또는 기간별(예: 행사 단위) 정산.
- **명세서:** 알바생 화면에서 실시간 조회 + PDF/카톡 문구로 보내기. 임금명세서 필수 기재 항목을 지킨다(⚠️확인 — 2021.11 시행 임금명세서 교부 의무).
- 지급 완료 체크와 지급 내역(날짜·금액) 기록.

### 2.5 근로계약서 관리

- 표준근로계약서(단시간·기간제 포함) 양식에 근로 조건을 자동으로 채운다.
- 알바생이 휴대폰에서 서명 → PDF 생성·보관, 양쪽이 언제든 다시 받기.
- 근로 조건이 바뀌면 새 계약서로(옛 계약서는 보관). 서명 전/후 상태 표시.

### 2.6 신고·세무 자료 (A·B·C)

| 서류 | 기한 | 대상 | 지금 상태 |
|---|---|---|---|
| 근로내용 확인신고서(일용, 고용·산재) | 다음 달 15일 ⚠️확인 | 일용근로자 전원 | PDF 서식 ✅, 사람 선택·주방/캐셔 분리 ✅ |
| 일용근로소득 지급명세서(국세청) | 다음 달 말일 ⚠️확인 | 일용근로자 | 근로내용 확인신고서의 국세청 칸으로 갈음 가능 ⚠️확인 — 칸 채우기 필요 |
| 국민연금·건강보험 자격취득신고 | 다음 달 15일 ⚠️확인 | 가입 대상자 | 대상 판정 ✅, 신고서는 없음(명단 엑셀만) |
| 세무사 전달용 인건비 엑셀 | 매달 | 전원 | ✅ (근무일 1~31 표시, 주민번호, 입사일, 보수) |
| 원천징수이행상황신고 자료 | 다음 달 10일 ⚠️확인 | 3.3%·근로소득세 | 없음 — 합계표 필요 |

**출시 전 꼭 확인할 것:** 고용·산재 토탈서비스의 **엑셀 일괄신고 양식** 형식. PDF보다 이 파일을 바로 올릴 수 있게 만드는 쪽이 사장님에게 훨씬 쓸모 있다.

## 4. 도메인 규칙 (제품의 핵심 — 테스트 기준이 된다)

모든 규칙은 `rules/` 아래 순수 함수 + 테스트 + **근거(법 조항·공단 안내 링크)** 주석으로 둔다. 연도마다 바뀌는 숫자는 코드가 아니라 DB 테이블.

### 4.1 근로자 유형

| 유형 | 정의(요약) | 신고 | 보험 |
|---|---|---|---|
| 일용 | 1개월 미만 고용, 날마다 근로계약 ⚠️확인 | 근로내용 확인신고(매월) | 고용·산재 전원, 국민연금·건강보험은 판정 |
| 단시간 | 주 소정근로 40시간 미만 상시 고용 | 취득·상실 신고 | 월 60시간 이상이면 4대보험 ⚠️확인 |
| 상용 | 그 외 | 취득·상실 신고 | 4대보험 |
| 사업소득(3.3%) | 근로자가 아닌 프리랜서 | 사업소득 지급명세서 | 4대보험 없음 — **근로자에게 3.3%만 떼는 건 위험**(근로자성 판단 ⚠️) |

### 4.2 근무시간·휴게

- 유급 시간 = 실근무 − 휴게. 휴게 우선순위: 근무일별 > 파트 고정 > 기본값 (지금 규칙).
- 법정 휴게: 4시간 30분 이상, 8시간 1시간 이상 ⚠️확인 → 부족하면 경고.
- 합계는 분 단위로 더한 뒤 마지막에 한 번만 시간으로 바꾼다.

### 4.3 수당 (지금 코드에 없음 — 새로 만든다)

| 수당 | 조건 ⚠️확인 | 계산 |
|---|---|---|
| 주휴수당 | 1주 소정근로 15시간 이상, 소정근로일 개근 | 1일 소정근로시간 × 시급 |
| 연장 가산 | 5인 이상 사업장, 1일 8시간·1주 40시간 초과 | 50% |
| 야간 가산 | 5인 이상, 22:00~06:00 | 50% |
| 휴일 가산 | 5인 이상, 휴일 근로 | 8시간 이내 50%, 초과 100% |
| 최저임금 | 2026년 시급 10,320원 ⚠️확인 | 미달이면 등록 단계에서 막거나 경고 |

사업장 상시 근로자 수(5인 이상 여부)는 사업장 설정 + 자동 추정(월 평균) 둘 다.

### 4.4 공제 (지금 코드에 있음)

| 항목 | 근로자 부담 ⚠️확인 | 계산 |
|---|---|---|
| 국민연금 | 4.75% (2026, 9.5%의 절반) | 기준소득월액 천 원 미만 절사, 하한·상한(매년 7월), 10원 미만 절사 |
| 건강보험 | 3.595% (7.19%의 절반) | 10원 미만 절사 |
| 장기요양 | 건강보험료의 13.14% | 10원 미만 절사 |
| 고용보험 | 0.9% | 원 미만 절사 |
| 3.3% | 소득세 3% + 지방소득세 0.3% | 각 10원 미만 절사 |
| 일용근로소득세 (새로) | (일급 − 15만 원) × 6% × (1 − 55%) | 지방소득세 10%, 소액부징수 1,000원 미만 ⚠️확인 |
| 근로소득세 (상용, 후순위) | 간이세액표 | 표 데이터 필요 |

- 한 사람이 여러 매장·프로필이면 **사람 단위로 한 번 계산해서 나눈다**(지금 `splitSocialInsurance`).
- 공제는 저장 시점 금액으로 고정, 근무가 바뀌면 "다시 계산" 표시(지금 방식).
- 두루누리 지원(10인 미만, 신규 가입자 80% ⚠️확인)은 고지 금액에 반영되므로 표시 옵션으로.

### 4.5 국민연금·건강보험 가입 판정 (지금 코드에 있음)

- 한 달에 8일 이상 · 60시간 이상 · 월 220만 원 이상 중 하나, **단 전 달부터 이어서 근무** (Hiyorisando 기준, 2026-11-02 의정부지사 문의) ⚠️일반화 전 재확인.
- 건강보험이 같은 기준인지 공단(1577-1000) 확인 필요.

### 4.6 신고 자료 규칙 (지금 코드에 있음)

- 입사일 = 이번 달까지 끊김 없이 이어진 근무의 첫날.
- 일평균 근로시간 칸: 하루 평균 / 총 시간 선택 (지금까지 총 시간을 써 왔다 — 공단 확인 ⚠️).
- 기본 제외: 월 보수 50만 원 이하 (Hiyorisando 운영 기준 — 법 기준 아님, 사업장 설정으로).
- 직종부호·이직사유 코드: 사업장/알바생 설정 (지금은 61·87·1 고정).

## 6. 보안·개인정보·법적 고지

- **주민등록번호:** 4대보험·근로내용 신고에 법적 근거가 있는 사업주의 처리 → 우리는 **수탁자**. 개인정보 처리방침, 위탁 계약 조항, 암호화(지금 `pii-crypto`), 열람 기록, 퇴사 후 보관 기간 ⚠️노무·법률 확인.
- **위치 정보(휴대폰 출근):** 위치정보법 동의 ⚠️ — MVP는 키오스크·사장님 입력만으로 시작해도 된다.
- **신고 대행 금지 선:** 앱은 사장님이 직접 신고할 서류·파일을 만든다. 대신 제출하면 세무대리·노무 대행 영역 ⚠️.
- **계산 책임 고지:** "참고용 계산, 최종 확인은 세무사·공단" — 서류 다운로드 화면마다.
- 요율·규칙 변경 공지(매년 1월·7월) 체크리스트.

## 7. MVP와 일정 (혼자 개발 기준, 대략)

| 주 | 할 일 | 완료 기준 |
|---|---|---|
| 0 | 규칙 문서(4장) 확정 — 공단·세무사 확인, 근로자 유형 범위 결정 | ⚠️확인 항목 80% 해소 |
| 1–2 | 새 저장소, org_id·RLS 스키마, 가입·사업장 생성·초대, 3장 코드·테스트 이식 | 테스트 전부 통과, 사업장 2개 격리 테스트 |
| 3 | 알바생 등록·관리, 매장 | 초대 링크 가입 |
| 4 | 출퇴근(키오스크·사장님 입력), 수정 이력, 오늘 보드 | 출퇴근 → 근무 확정 |
| 5 | 급여: 기본급·주휴수당·공제·조정 항목·명세서(알바생 화면, PDF/카톡 문구) | Hiyorisando 10월 데이터로 금액 일치 |
| 6 | 근로계약서 이식, 신고 자료(엑셀·근로내용 PDF) 이식 + 사업장 설정 주입 | 10월분 서류가 지금과 같은 결과 |
| 7 | 결제(구독), 개인정보 처리방침·약관, 모니터링, 베타 | 베타 사업장 3곳 |

**MVP에서 뺀다:** 가산수당 자동(5인 이상 사업장은 경고만), 상용직 근로소득세, 휴대폰 위치 출근, 전자신고 연동, 근무표 고급 기능.

## 8. 검증 계획

1. **출시 전:** 알바 쓰는 사장님 5~10명에게 Hiyorisando에서 뽑은 서류(가린 버전)를 보여 주고 묻는다 — 지금 이걸 어떻게 하고 있나, 얼마나 걸리나, 월 얼마면 쓰겠나.
2. **베타:** 3곳 무료. 한 달 돌리고 세무사에게 서류를 그대로 넘길 수 있었는지 확인.
3. **지표:** 월 신고 자료 다운로드 사업장 수(핵심), 출퇴근 기록률(근무표 대비), 급여 확정까지 걸린 시간.

| 플랜 | 대상 | 가설 |
|---|---|---|
